VaultWatch now finds your vaults by itself — no more importing or adding folders by hand.

## New: vault auto-detection

- **Three sources, merged and deduped**: vaults configured for Headless Sync (`ob sync-list-local`), every vault desktop Obsidian knows about (its own vault registry), and vaults in the iCloud Obsidian folder (created on iPhone/iPad).
- **Keeps watching**: scans at launch and every 5 minutes, so a vault you set up later just appears. New finds post a notification.
- **Sensible defaults**: vaults already set up with `ob sync-setup` start syncing immediately; the rest show up stopped with a one-click path to **Set Up in Terminal…**.
- **Respects your choices**: a vault you remove stays removed (adding it back by hand clears that), and **Auto-Detect New Vaults** can be turned off in the gear menu.
- **Detect Vaults Now** in the gear menu replaces *Import Vaults from ob*.

## Fixes & internals

- New `VaultDiscovery` source of truth for finding vaults; paths are normalized (symlinks, trailing slashes, case) so the same vault can't be added twice.
- Config gains `ignoredPaths`; older `config.json` files load unchanged.
- Re-checking binaries after installing `ob` now also re-detects vaults.
