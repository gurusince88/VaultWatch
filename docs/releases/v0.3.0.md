First public release of VaultWatch: a macOS menu bar app that keeps Obsidian Headless Sync (`ob sync --continuous`) running in the background and shows you what it's syncing.

## What's in it

- **Menu bar status**: `ob ✓` up to date, `ob …` syncing, `ob !` needs attention, `ob ⏸` paused.
- **Activity view**: every file uploaded, downloaded, merged, or deleted, with today's counts, filters, and search.
- **Keeps sync alive**: automatic restart with backoff, clean shutdown on quit/logout/sleep, restart after wake.
- **Safe by default**: refuses to run two syncs on one vault and offers **Take Over** if one is already running.
- **Zero setup**: imports the vaults you configured with `ob sync-setup` on first launch.
- Per-vault logs, continuous or interval mode, Launch at Login.

Not affiliated with Obsidian. Needs an Obsidian Sync subscription.
